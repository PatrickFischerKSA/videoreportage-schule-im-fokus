# Schule im Fokus

Statische GitHub-Pages-Plattform zum Projekt **Videoreportage «Schule im Fokus»**.

## Inhalt

- Projektauftrag und Anforderungen
- Werkstatt-Ablauf von Beobachtung bis Schnitt
- Themenfinder
- fokussierte Lernfilm-Ressourcen von Rainer Wolf / Wolffilms
- Publikationsstruktur nach dem Vorbild des Blaue-Becher-Beitrags
- Qualitätskompass und Abgabe-Checklisten
- Originalauftrag unter `assets/Videoreportage_Schule_im_Fokus.docx`

## Lokal öffnen

Die Plattform funktioniert ohne Build-Schritt. `index.html` kann direkt im Browser geöffnet werden.

## Auf GitHub Pages veröffentlichen

1. Repository auf GitHub erstellen.
2. Diese Dateien in das Repository hochladen.
3. Unter `Settings` → `Pages` die Quelle `Deploy from a branch` wählen.
4. Branch `main` und Ordner `/root` auswählen.
5. Die veröffentlichte URL nach dem Deployment öffnen.

## Videos ergänzen

In `index.html` können die Platzhalter in der Galerie später durch echte Video-Embeds oder lokale Videodateien ersetzt werden.
